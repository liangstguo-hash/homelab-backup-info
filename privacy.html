HomeLab Backup 隐私说明

更新日期：2026-09-29

用途与处理的数据

HomeLab Backup 是账户所有者自用的本机备份工具。它处理所有者选择的本地文件、配置、数据库导出、备份运行日志、Google Drive 容量信息及用于访问备份文件的 OAuth 凭据，目的为备份、完整性验证和恢复。

Google Drive 权限

工具请求 drive.file 权限，仅访问由此应用创建或由用户明确授权给此应用的文件。此权限用于创建备份目录、上传加密数据、列举备份、下载恢复数据，以及执行所有者启用的历史保留策略。

存储与共享

备份内容由 Restic 在本机加密，再上传到账户所有者的 Google Drive。OAuth 凭据和运行用的恢复密码保存在本机受限目录；所有者另行保存恢复密码。运行日志和暂存文件保存在本机。Google 按其自身服务条款与隐私政策处理云端存储和授权相关信息。本工具不经营广告或数据销售服务，也不把备份内容提供给其他用户。

保留与删除

备份保存至所有者手动删除或启用的保留策略执行删除为止。撤销 Google 授权会阻止后续访问，但不会自动删除现有云端备份。本机凭据、日志与暂存数据由所有者管理。失去恢复密码可能导致加密备份无法恢复。

本说明网站

本说明网站采用 GitHub Pages 托管，不设置登录表单、广告或网站分析脚本。托管服务可能为提供和保护服务处理访问者 IP 地址等技术信息，详见 GitHub 隐私声明。本网站不接收备份内容、OAuth 凭据或恢复密码。

控制与联系

所有者可停止备份任务、更改备份范围，或在 Google 账户的第三方连接设置中撤销授权。需要支持时，请使用 Google 授权页面显示的应用支持邮箱。
